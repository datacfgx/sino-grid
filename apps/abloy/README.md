# ABLOY

**O anti-furto Android open-source.** O celular roubado vira tijolo, o ladrao vira evidencia.

Furto com ABLOY nao e mais crime do lucro - e crime do prejuizo.

## O que o ABLOY faz

- **Evidencia**: a partir do 2o erro de desbloqueio, fotografa + localiza e manda no SEU Telegram (BYO: seu bot, seu chat, zero servidor nosso)
- **Comandos por Telegram**: /localizar /foto /alarme /trancar /wipe /status /destravar
- **Wipe remoto** (duas etapas): com FRP ativo, tijolo pro ladrao, voce restaura seu backup
- **SMS emergencial**: numero de confianca manda localizar + PIN, recebe coordenadas sem internet
- **Disfarce**: calculadora funcional; seu PIN + = abre o painel
- **Anti-desinstalacao**: desativar exige o painel do proprietario

## O que o ABLOY NAO faz (contrato de honestidade)

- Nao impede wipe pelo recovery - o FRP transforma o aparelho apagado em tijolo pra quem roubou
- Nao impede desligamento forcado (power 10s e hardware)
- Nao funciona em aparelho eternamente offline (o SMS cobre o essencial)
